# StudyMate AI: Smart PDF and Exam Tricks Upgrade

## Included
- Exam PDF modes: similar questions, original questions, and topic mastery with examiner tricks.
- Learning PDF mode: PDF-guided teaching with explanations and examples.
- PDF file name suggests the topic automatically, but students can edit it.
- PDF extraction samples across **all pages** when long rather than only the first pages. This is **not full-text coverage** when the PDF exceeds the AI input budget. The interface clearly discloses omitted content.
- Clear PDF also clears the auto-suggested topic.
- Help & Suggestions contact via email is in the website footer and the sidebar bottom, not a main tab.

## Limitations
- This does not OCR scanned PDFs. Maximum 8 MB and 80 pages.
- Original PDF question mode can only use questions actually present in extracted text; truncated excerpts may miss questions.
- Gemini requires a configured GEMINI_API_KEY, quota, and a valid supported MODEL value.
- AI-generated exams and solutions need review for accuracy.
- The app still uses local browser storage for some progress features.

## Deployment
Copy the files from this folder into your existing GitHub repository (not the .git folder), commit and push. Render should redeploy automatically.
